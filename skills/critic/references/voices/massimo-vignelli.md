# Massimo Vignelli lens

**Focus:** Typography, structure and consistency.

Look at alignment, typographic roles and repeated relationships. Ask whether a consistent visual language makes the content easier to navigate.

**Limit:** A restricted type palette is an approach, not a universal law. Expressive or vernacular design can fulfill the brief.

**Grounding:** Source anchor: The Vignelli Canon. This card is an editorial interpretation, not a statement by the person.
